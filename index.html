START WITH THE WHY

Reuse code.
Understand classes.

Inheritance lets one class take on the fields and methods of another. In Java, the child class uses extends to inherit from a parent class.

class Car extends Vehicle { }

Think of it like a family: a child gets shared traits, then adds its own.

YOUR FIRST INHERITANCE EXAMPLE

Watch a Dog reuse Animal’s code.

You do not need to memorize the code yet. Follow the class names and look for the word extends.

01
Find the parent class

Animal has an eat() method that can be shared.

02
Find the child class

Dog extends Animal means Dog inherits from Animal.

03
Use the inherited method

A Dog object can call eat(), even though eat() is written in Animal.

Quick vocabularyclass a kind of objectmethod an action a class can doobject one usable example of a class
JAVA EXAMPLESingle inheritance
class Animal {
    void eat() {
        System.out.println("Animal is eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog is barking");
    }
}

class Main {
    public static void main(String[] args) {
        Dog pet = new Dog();
        pet.eat();
        pet.bark();
    }
}
PROGRAM OUTPUT
Animal is eating
Dog is barking
REMEMBER

The arrow points from the child to the parent idea: Dog extends Animal, so Dog can reuse Animal’s methods.
