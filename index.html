WHY INHERITANCE MATTERS

Write shared logic once. Specialize in child classes.

In Java OOP, inheritance creates an IS-A relationship. A subclass reuses non-private fields and methods from its superclass and adds specialized behavior.

class Car extends Vehicle { void openTrunk() {} }
Inherited: move(), fuelType Added by Car: openTrunk() Rule: One parent class via extends

B.TECH EXAM CHEAT SHEET

4 Rules Tested in Viva & Semester Exams.

CONSTRUCTORS

Parent runs first

Constructors are not inherited, but super() runs automatically so the Parent constructor finishes before the Child constructor.

VISIBILITY

private stays private

Subclasses inherit public and protected members. private fields belong strictly to the parent class.

RESTRICTION

final stops inheritance

A final class cannot be extended, and a final method cannot be overridden by any child class.

SYNTAX ORDER

extends before implements

Always write class Dog extends Animal implements Pet. Putting implements first causes a compile error.
